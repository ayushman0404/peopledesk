# Contributing

Follow README.md to run the app, then **python scripts/check.py**. Keep a change focused on one user problem and include a reproduction or meaningful check.

Useful contributions include setup clarity, accessibility, permission boundaries, provider error handling and reproducible assistant failures. Read SECURITY.md before changing authentication or messaging.

Use fictional data in issues and screenshots. Do not post employee records, credentials or private chats. Send vulnerability details privately to the maintainer email in SECURITY.md.

For pull requests, explain the trigger, resulting behaviour, checks and limits. Mention relevant AI assistance and distinguish provider doubles from live-account testing.

Maintained by Ayushman Choudhary. Response times and support service levels are not guaranteed. Custom client work requires a separately agreed scope.
